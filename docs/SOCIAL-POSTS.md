## Tips
- Post the "Join announcement" first, then post one whenever something ships.
- Tag **@QVAC**, use **#teamSehat**, attach media (a photo of the actual PC + phone
  beats a plain screenshot).
- Reply to your own first post to build a running thread (threads get more engagement).
- If you livestream a coding session, save the VOD link — judges can validate it.
- Sehat's brain is **QVAC MedPsy-4B** (Tether's own model). When mentioning speed,
  compare *against* Google's MedGemma as a benchmark — we run MedPsy, not MedGemma.
